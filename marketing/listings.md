# Listing copy

## Short description

Sixteen focused skills for product, engineering, design, and writing decisions.

## Long description

WyStack Agent Kit helps capable coding agents make better product and engineering decisions without imposing a task tracker or lifecycle. Its sixteen skills cover product definition, technical design, estimation, review, runtime verification, frontend design, UX writing, copywriting, and discoverability. Each skill owns one distinct transformation, follows project conventions, and loads extra reference material only when relevant.

## Keywords

agent skills, software development, product requirements, architecture decisions, code review, verification, frontend design, UX writing, copywriting, discoverability

## Differentiator

The kit is deliberately small: semantic boundaries are preserved, procedural wrappers are not. A project can use any skill independently and keep its own templates, tools, and workflow.
