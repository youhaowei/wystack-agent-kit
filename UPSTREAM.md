# Source lineage

WyStack Agent Kit is a synthesis, not a maintained fork. External ideas are ported selectively when they make one of the retained skills materially better.

## Influences

- [Matt Pocock's skills](https://github.com/mattpocock/skills) — context-efficient skill writing, trigger design, progressive disclosure, and completion criteria.
- [obra/superpowers](https://github.com/obra/superpowers) — brainstorming, planning, review, and verification discipline.
- [garrytan/gstack](https://github.com/garrytan/gstack) — pragmatic software-development workflows and product judgment.
- [pbakaus/impeccable](https://github.com/pbakaus/impeccable) — distinctive interface direction and named design anti-patterns.
- [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) — copywriting and discoverability reference material.
- Anthropic's frontend-design material — product-quality interface principles.

## Policy

- Port concepts, not upstream choreography.
- Keep attribution and license obligations intact.
- Do not mirror a new upstream skill unless it owns a distinct judgment the current set lacks.
- Prefer improving a retained skill or a conditional reference over expanding the catalog.
- Re-evaluate old imports against the current minimal-surface standard when upstreams change.

The JSON baseline files under `plugins/wystack-agent-kit/` record the last known source pins and imported concepts. They are historical provenance, not an automatic synchronization contract.
